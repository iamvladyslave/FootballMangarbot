# Football Manager Bot

Telegram-бот для футбольного менеджера с функциями:
- Информация о менеджере
- Расценки на услуги
- Условия работы
- Сбор контактов клиентов
- Админ-панель для редактирования контента

## Деплой на Vercel

### 1. Подготовка
- Все файлы уже готовы для деплоя
- `api/webhook.py` - основной код бота
- `vercel.json` - конфигурация Vercel
- `requirements.txt` - зависимости

### 2. Настройка переменных окружения
В Vercel добавьте переменную:
- `TELEGRAM_BOT_TOKEN` = ваш токен бота

### 3. Настройка webhook
После деплоя настройте webhook:
```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://your-bot.vercel.app/api/webhook
```

## Функции бота
- **Команды**: /start, /menu, /tasks, /pricing, /terms, /contact
- **Админ**: @matagency_official
- **Анкета**: сбор возраста, имени, контакта
- **Редактирование**: админ может менять тексты и добавлять фото
